## Запуск

Усі команди виконуються з папки проекту.

1. Встановлення залежностей:
   ```bash
   pip install -r requirements.txt
   ```
2. Виконання всіх завдань лабораторної (результати виводяться в консоль, розшифрований текст зберігається в `data/decrypted_v10.txt`):
   ```bash
   python main.py
   ```
3. Побудова графіків (зберігаються в `plots/`):
   ```bash
   python generate_plots.py
   ```

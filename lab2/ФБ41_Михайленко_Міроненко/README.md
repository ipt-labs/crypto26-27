## Структура проекту
* `src/vigenere.py` — функції шифрування, розшифрування та попередньої обробки тексту.
* `src/stats.py` — розрахунок індексу відповідності (IC) та автокореляційної статистики ($D_r$).
* `src/attack.py` — автоматичний пошук довжини ключа $r$ та частотний криптоаналіз блоків.
* `generate_plots.py` — генерація графіків залежності $IC(r)$ та $D_r(r)$ у папку `plots/`.
* `main.py` — головна точка входу для виконання всіх пунктів лабораторної роботи.

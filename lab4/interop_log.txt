Сайт: http://asymcryptwebservice.appspot.com/?section=rsa   (дата перевірки: 31.10.2026)

Абонент A: n = 521 біт, p = 262 біт, q = 260 біт;  абонент B: n1 = 528 біт, p1 = q1 = 264 біти;  e = 65537 (на сайті 10001 hex), n <= n1.
Ключі зберігаються у key_A.json / key_B.json (створює gen_RSA_pair.py), відкритий ключ сервера - командою `server`.

Як читати журнал:
  рядки, що починаються з `$`   - команди нашої програми (site_interop.py) та її вивід;
  рядки, що починаються з `>>>` - що введено на сайті і що сайт повернув (скріншот вказано в дужках);
  значення на сайті - hex, тип повідомлення Bytes (якщо не вказано Text); сайт повертає hex великими літерами.
Ключ сервера на сайті одноразовий для сесії (розділ Server Key). Для A -> сервер потрібно n1 >= n (взято 1024 біт),
для сервер -> B потрібно n1 >= n сервера (взято 512 біт, бо n_B має 528 біт).

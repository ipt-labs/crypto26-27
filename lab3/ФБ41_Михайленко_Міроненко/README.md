## Структура проекту

* `main.py` — головна точка входу для виконання всіх пунктів лабораторної роботи: математичний апарат (розширений алгоритм Евкліда, лінійні порівняння), частотний криптоаналіз біграм та розпізнавання змістовного тексту.
* `07 (utf8).txt` — вхідний файл із шифртекстом варіанта 7.
* `decrypted_07.txt` — результат дешифрування (змістовний відкритий текст).
* `requirements.txt` — залежності проекту.

---

## Запуск

Усі команди виконуються з папки проекту.

1. Встановлення залежностей (використовуються лише стандартні бібліотеки `math`, `collections`, `itertools`, тому встановлення додаткових пакетів не потрібне):
   ```bash
   pip install -r requirements.txt
   ```

2. Виконання всіх завдань лабораторної (результати аналізу та знайдений ключ виводяться в консоль, а розшифрований текст зберігається в `decrypted_07.txt`):
   ```bash
   python main.py
   ```
